The size button now opens the tool in your hand as well as the width: an Advanced fold with the two knobs that tool actually has — hair gauge for the paintbrush, flow for the airbrush, pressure for the crayon, a feathered edge for the paint bucket, opacity for the rest — kept per tool, so a soft brush stays soft without softening anything else.
